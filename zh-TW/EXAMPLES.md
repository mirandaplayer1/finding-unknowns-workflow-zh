# 實際可貼的觸發範例

每個 skill 給 1–3 個真實 prompt，複製、改成你的題目、貼進 Claude Code 就能用。

## /kickoff — 開案

```
我想做一份給非技術同仁的 AI 工具入門教材，大概兩小時的工作坊用。
```

```
開案。我手上只有一個粗略想法：幫團隊做一個每週自動整理會議記錄的東西。
```

在空資料夾直接說第一句就可以——骨架缺件會先自動建好，再開始起草規格。

## /scout — 競品調查

```
這個「通知設定」功能業界怎麼解？我有三種做法選不出來，幫我做競品調查。
```

```
找競品：別人的 onboarding 都怎麼處理第一次使用的空狀態？
```

## /interview — 訪談

```
訪談我。規格的未知清單裡還有幾條沒收斂。
```

```
動工前最後確認一次，把規格裡模糊的地方問清楚。
```

## /blindspot — 盲點掃描＋領域教學

```
掃盲點。這個專案要做影片調色，我完全不懂這個領域，順便教我怎麼下指令。
```

```
幫我找未知：這份規格我覺得寫完了，但我怕有整塊沒想到的面向。
```

## /quiz — 交付前測驗

```
考我。這輪做完了，交付前確認我真的懂。
```

## /pitch — 說帖

```
包一份給主管看的說帖，我要拿到核准。重點是風險我們都想過了。
```

## /reflect — 復盤（記得開新對話）

```
反思。上一輪工作結束了，幫我復盤並決定哪些教訓值得晉升成規則。
```
