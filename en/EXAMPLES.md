# Real Prompts You Can Paste

1–3 real prompts per skill. Copy one, swap in your own topic, paste into Claude Code.

## /kickoff — project kickoff

```
I want to make an intro course on AI tools for non-technical colleagues — roughly a two-hour workshop.
```

```
Kickoff. All I have is a rough idea: something that automatically summarizes our meeting notes for the team every week.
```

In an empty folder, just say the first line — missing scaffold files get created automatically, then spec drafting begins.

## /scout — competitive research

```
How does the industry solve this "notification settings" feature? I have three approaches and can't pick — do a competitive analysis for me.
```

```
Find competitors: how do other products handle the first-use empty state in onboarding?
```

## /interview — interview

```
Interview me. The spec's unknowns list still has a few items that haven't converged.
```

```
One last check before we start — ask me about every fuzzy spot in the spec.
```

## /blindspot — blind-spot scan + domain teaching

```
Scan for blind spots. This project involves video color grading and I know nothing about the domain — teach me how to give instructions while you're at it.
```

```
Find my unknowns: I think this spec is finished, but I'm worried there's a whole angle I never considered.
```

## /quiz — pre-delivery quiz

```
Quiz me. This round is done — before delivering, confirm I actually understand it.
```

## /pitch — pitch

```
Package a pitch for my manager — I need approval. The key message is that we've thought through the risks.
```

## /reflect — retrospective (remember: new conversation)

```
Reflect. The last round of work is finished — run the retrospective and decide which lessons deserve promotion into rules.
```
